Privacy

Effective date: November 25, 2026. This page covers the Never Lose Tabs Chrome extension (version 1.0.0) and this website. Never Lose Tabs is made by BigPoppaDev.

The short version: the tabs you save stay in Chrome on your computer. Never Lose Tabs doesn't send them to us or anyone else, and it has no ads, analytics or tracking.

What the extension stores, and where

When you click Save all tabs in this window, Never Lose Tabs reads the web address (URL) and title of each tab in that window and saves them in your browser's own extension storage on your computer. It also stores:

  • The date and time each group was saved, and any group name.
  • Daily backup copies of your saved tabs, kept for the last 3 days.
  • A few small settings: how many times you've saved (used once to ask for a rating), whether you've answered that ask, and a note after each update saying how many tabs came through it.

The extension only reads your tabs when you click its save button. It does not watch or record the pages you visit.

What leaves your computer

Nothing, unless you choose it:

  • Export backup file saves a file with your saved tabs wherever you choose. What happens to that file is up to you.
  • Import a file and Import from OneTab read only the file or text you give it, on your computer.
  • Rate it opens Never Lose Tabs' page in the Chrome Web Store, which Google runs under its own privacy policy.
  • If you remove the extension, Chrome opens a page on this website asking why. Answering is optional and opens an email you choose whether to send.

Never Lose Tabs has no servers of its own. It does not sell, rent or share your information, and it does not use it for advertising or to decide credit or lending. Our use of information follows the Chrome Web Store User Data Policy, including its Limited Use requirements.

This website

This website is hosted on GitHub Pages. GitHub may log visitors' IP addresses for security, as described in GitHub's own privacy statement. We don't add any analytics or tracking to this site.

Removing your data

You can delete any group or tab on the Saved tabs page. Removing the extension from Chrome deletes everything it stored, including the daily backups. Backup files you exported stay wherever you saved them until you delete them.

Children

Never Lose Tabs is not directed at children under 13, and we don't knowingly collect information from them.

Changes to this policy

If this policy changes, the new version will be posted here with a new effective date. If a change affects what the extension stores or sends, we'll say so in its Chrome Web Store listing too.
