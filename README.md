# Large Print Reader website

The public pages for Large Print Reader, a Chrome extension by BigPoppaDev.

- Home: https://bigpoppadev.github.io/largeprintreader/
- Privacy: https://bigpoppadev.github.io/largeprintreader/privacy/
- Refunds and cancelling: https://bigpoppadev.github.io/largeprintreader/refunds/
- Large Print Crosswords home: https://bigpoppadev.github.io/largeprintcrosswords/
- Large Print Crosswords privacy (account deletion steps at `#delete`): https://bigpoppadev.github.io/largeprintcrosswords/privacy/

Plain HTML, CSS and one small script. Nothing to build: edit the files in `largeprintreader/` or `largeprintcrosswords/` and the site updates. The crossword pages share `largeprintreader/site.css`.

The crossword app icons in `largeprintcrosswords/` come from the logo master (BPD_logo_large-print-crosswords_v1_2026-11-18.svg in the BPD - BigPoppaDev Drive folder).

The pictures and icons are made by `tools/make_assets.py`. The "Build page images" workflow runs it and saves the results.
